Assumptions & scope

  • Built on synthetic orders and publicly-known Indian MF mechanics (BSE StAR MF / RTA flows, 3:00 PM equity NAV cut-off, T+1 allotment, NACH/UPI mandates).
  • Not a Dezerv system and uses no Dezerv data — a product-judgment artifact, not an integration.
  • Reconciliation logic is a three-way match (bank debit ↔ order value ↔ allotment value); deltas open a break.
  • Designed to demonstrate ownership of execution outcomes: lifecycle state, cut-off risk, payment-to-order matching, recon exceptions, operator action, transparent client status.
